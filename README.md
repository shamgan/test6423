# מערכת מבחן דיגיטלית בגיאוגרפיה (מתכונת אדם וסביבה)

אפליקציית מבחן אינטראקטיבית בעברית המיועדת להרצה בדפדפן (מחשב או טאבלט) ובפרט תחת סביבה נעולה של **Safe Exam Browser (SEB)**.
המערכת היא קובץ עצמאי יחיד (`index.html`) המכיל את כל העיצוב, הלוגיקה והמדיה (תמונות המקודדות בתוך הקוד כ-Base64) ללא צורך בחיבור לשרת או בסיס נתונים.

---

## תכונות מרכזיות

1. **ניהול חוקי מענה מורכבים:**
   - המערכת אוכפת את כללי הבגרות: בחירה של **שתי** שאלות מפרק ישראל **או** **שתי** שאלות מפרק המזרח התיכון, ובנוסף **שלוש** שאלות מפרק נתי"ב (רוסיה - שאלה 11 היא שאלת חובה, בתוספת 2 שאלות בחירה).
   - מנגנון בחירה נוח (Checkbox) המפעיל/משבית את שדות הכתיבה של השאלה ומעדכן את מוני ההתקדמות בזמן אמת.
   - תמיכה בשאלה 3 (היגדים): בחירה של 3 היגדים מתוך 5, קביעת "נכון/לא נכון" וכתיבת הסבר.
   - תמיכה בשאלה 11 (חובה): בחירה ומענה על לפחות 3 סעיפים מתוך 4.

2. **אבטחה ויומן חריגות (צד-לקוח):**
   - **בקרת מסך מלא:** המערכת דורשת מעבר למסך מלא בהתחלה ומתריעה בבאנר אדום בולט במקרה של יציאה ממסך מלא.
   - **מעקב יציאות:** האזנה לאובדן פוקוס מהחלון (`window.blur`) ומעבר לכרטיסייה אחרת (`visibilitychange`). כל יציאה מתועדת ביומן עם חותמת זמן מדוייקת.
   - **חסימת פעולות:** חסימת תפריט קליק ימני (`contextmenu`), חסימת הדבקת טקסט (`paste`) לתוך שדות התשובות (ותיעודה כחריגה).
   - *הבהרה:* זיהוי החריגות בדפדפן רגיל הוא הרתעתי. לנעילת המחשב לחלוטין יש להריץ את המבחן בתוך Safe Exam Browser (ראה פירוט בהמשך).

3. **שמירה אוטומטית (עמידות לקריסות):**
   - המערכת שומרת את תשובות התלמיד ואת יומן החריגות ב-`localStorage` באופן אוטומטי בכל שינוי (כל שנייה בדיליי קטן).
   - בטעינת הדף, אם קיימת טיוטה שמורה - יוצג חלון שחזור המאפשר להמשיך מהמקום שבו המבחן נעצר במידה והדפדפן נסגר בטעות.

4. **הגשה וייצוא PDF בטוח לעברית:**
   - בלחיצה על "סיום והגשה", המערכת מבצעת אימות בחירה.
   - המערכת מייצרת PDF מעוצב ונקי המכיל את פרטי הזיהוי של התלמיד, חותמת זמן, **רק את השאלות שנבחרו והתשובות שנכתבו** (במבנה נקי וקריא), ובסופו **יומן חריגות מלא**.
   - ה-PDF מיוצר באמצעות שילוב של `html2canvas` ו-`jsPDF` (צילום ה-DOM הסטטי של התשובות ופיצולו לעמודים), המבטיח ייצוא עברית מושלם ללא בעיות של היפוך אותיות או גופנים שבורים.

## מבנה הפרויקט

- `index.template.html` - תבנית המקור של האפליקציה המכילה את ה-HTML, ה-CSS (כולל תמיכה בערכת עיצוב כהה/בהירה), מבנה הנתונים הגיאוגרפי והלוגיקה ב-JavaScript.
- `build.ps1` - תסריט PowerShell הממיר אוטומטית את 8 התמונות (מהרינדור של קובץ ה-Word בתיקיית `extracted_docx\word\media`) לקוד Base64 ושותל אותן בתוך קובץ ה-`index.html` הסופי.
- `index.html` - הקובץ הסופי והעצמאי המיועד להפצה.

אם ברצונך לערוך את המבחן (שינוי ניסוח שאלות, נקודות וכו'):
1. ערוך את קובץ `index.template.html`.
2. הרץ בטרמינל/PowerShell את תסריט הבנייה:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1
   ```
3. קובץ ה-`index.html` יתעדכן בהתאם.

## הוראות העלאה ל-GitHub Pages (אירוח סטטי בחינם)

מכיוון שהמערכת היא קובץ HTML יחיד ללא תלות בשרת, היא מתאימה בצורה מושלמת לאירוח חינמי ב-GitHub Pages:

1. צור מאגר (Repository) חדש בחשבון ה-GitHub שלך (לדוגמה: `geography-exam`).
2. העלה את קובץ ה-`index.html` שיצרת אל התיקייה הראשית במאגר.
3. כנס להגדרות המאגר (**Settings**) בסרגל העליון ב-GitHub.
4. בסרגל הצדדי, תחת קטגוריית "Code and automation", לחץ על **Pages**.
5. תחת סעיף "Build and deployment", בחר במקור (**Source**) כ: **Deploy from a branch**.
6. תחת **Branch**, בחר ב-`main` (או `master`) ובתיקייה כ-`/ (root)`, ולחץ על **Save**.
7. לאחר כדקה, האתר יהיה זמין בכתובת:
   `https://<YOUR_GITHUB_USERNAME>.github.io/geography-exam/`

## הגדרת קובץ `.seb` עבור Safe Exam Browser (נעילת המחשב)

כדי למנוע מהתלמידים גישה לקבצים מקומיים, מנועי חיפוש או יישומים אחרים במהלך הבחינה, יש לנעול את המחשב באמצעות Safe Exam Browser:

1. הורד והתקן את **Safe Exam Browser** במחשבי בית הספר (או במחשבי התלמידים).
2. פתח את אפליקציית **SEB Config Tool** המותקנת יחד עם הדפדפן.
3. **הגדרות כרטיסיית General:**
   - בשדה **Start URL**, הזן את הכתובת של אתר המבחן ב-GitHub Pages שלך (למשל: `https://<YOUR_GITHUB_USERNAME>.github.io/geography-exam/`).
4. **הגדרות כרטיסיית Security:**
   - סמן ב-V אפשרויות המונעות מעבר חלונות, שימוש במנהל המשימות, או סגירת הדפדפן.
5. **הגדרות כרטיסיית User Interface:**
   - מומלץ לבטל את תצוגת סרגל הניווט (כפתורי קדימה/אחורה) כדי שהתלמידים יישארו רק בממשק המבחן.
6. **הגדרות כרטיסיית Quit Link / User Interface (סיסמת יציאה):**
   - הגדר **Quit Password** (סיסמת יציאה מהבחינה).
   - *חשיבות:* התלמידים לא יוכלו לסגור את הדפדפן או לצאת ממנו אל שולחן העבודה של מערכת ההפעלה ללא הזנת סיסמה זו, אותה המורה יקליד להם במחשב רק לאחר שווידא שהם הגישו את המבחן והורידו את קובץ ה-PDF.
7. שמור את קובץ ההגדרות דרך תפריט **File -> Save As** בשם `geography_exam.seb`.
8. הפץ את הקובץ `geography_exam.seb` לתלמידים. לחיצה כפולה על קובץ זה תפעיל את Safe Exam Browser במצב נעול מלא כשהוא טוען ישירות את דף המבחן שלך!
